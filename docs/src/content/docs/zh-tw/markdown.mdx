Hollo 支援 Markdown 貼文，包括表格和`~~刪除線~~`。
實例管理員可以透過 [`MARKDOWN_EXTENSIONS`][設定]啟用其他語法。
擴充功能適用於建立和明確編輯本機貼文的操作。
個人簡介和資料欄位繼續使用原有的 Markdown 語法。

[設定]: /zh-tw/install/env/#markdown_extensions-


啟用擴充功能
------------

在 *.env* 中設定所需擴充功能，然後重新啟動 Hollo：

~~~~ bash
MARKDOWN_EXTENSIONS=footnote,ruby,math
~~~~

可用名稱為`footnote`、`deflist`、`sub`、`sup`、`mark`、`ruby`、`ins`、
`abbr`、`tasklist`和`math`。未設定或為空時，所有擴充功能均關閉。
名稱前後的空白和重複名稱會被忽略；未知名稱會導致啟動失敗。

變更設定不會改變已儲存的原始文字或 HTML，也不會傳送既有貼文的更新。
明確編輯貼文時，會依目前設定重新呈現。因此，關閉擴充功能後編輯舊貼文，
可能會直接顯示其原始語法。


語法
----

| 擴充功能   | 原始文字                              | 含義                 |
| ---------- | ------------------------------------- | -------------------- |
| `footnote` | `正文[^1]`和`[^1]: 註腳`              | 帶編號的註腳         |
| `deflist`  | 術語的下一行寫`: 定義`                | 定義清單             |
| `sub`      | `H~2~O`                               | 下標                 |
| `sup`      | `x^2^`                                | 上標                 |
| `mark`     | `==醒目內容==`                        | 醒目標示的片段       |
| `ruby`     | `{漢字:ㄏㄢˋ ㄗˋ}`                    | 注音                 |
| `ins`      | `++新增內容++`                        | 插入的內容           |
| `abbr`     | `*[HTML]: Hyper Text Markup Language` | 縮寫定義             |
| `tasklist` | `- [x] 已完成`和`- [ ] 待完成`        | 靜態工作狀態         |
| `math`     | `$x^2$`和`$$x^2$$`                    | 行內和獨立顯示的公式 |

啟用對應擴充功能後，可以這樣寫：

~~~~ markdown
一個論點[^1]。HTML 具有元素。

[^1]: 補充說明。

術語
: 定義

*[HTML]: Hyper Text Markup Language

- [x] 撰寫
- [ ] 審閱
~~~~

註腳包含可見的編號和指向原始貼文的絕對連結。
定義清單包含用於區分術語和定義的可見標點。
注音包含在標籤被移除時使用的備用括號；Gukhanmun 會保留明確寫出的注音，
不會再巢狀加入讀音。

縮寫區分大小寫，並按單字邊界比對。`HTML5`、`html`和`HTML은`均不符合`HTML`。
在一般文字中首次符合時，會顯示完整解釋，如「HTML (Hyper Text Markup
Language)」。 連結文字、URL、提及、主題標籤、程式碼和公式不參與替換。
重複定義使用第一項；解釋內容作為純文字處理。

工作狀態保留為可見的`[x]`或`[ ]`文字，而非可點擊的核取方塊。
`[X]`也表示完成。標記之後需要空白或行尾。
透過編輯貼文變更狀態。`- [x]: note`這樣的行可能被視為 Markdown 連結定義，
而非工作。


跳脫和歧義
----------

要直接顯示語法，請使用行內程式碼，或在分隔符號前加反斜線。
啟用`sup`或`sub`後，表情符號和範圍中的成對插入號或波浪號可能變為格式。
寫成`\^_\^`或`1\~2,3\~4`即可保留原樣。
上下標內的空格必須跳脫，例如`x^a\ b^`。
原有的`~~刪除線~~`語法仍然可用。

啟用`footnote`時，`^[note]`是行內註腳；啟用`sup`時，`^[note]^`是上標。
接收軟體可能將上下標變成一般文字，因此也應以一般文字說明重要指數，
例如「x 的 a+b 次方」。


數學公式
--------

行內`$...$`不能跨行。開始的`$`後和結束的`$`前不能有空白，
結束的`$`後不能緊接數字。因此，`$5`和`$20 and $30`仍為一般的貨幣文字。
要顯示美元符號，請寫成`\$`或放在行內程式碼中。

獨立顯示的公式以行首的`$$`開始，允許縮排。
結束的`$$`之後，同一行只能有空白。也可以寫成單行`$$x^2$$`；
不支援句子中間的獨立顯示公式。

~~~~ markdown
行內公式是 $x^2$。

$$
\frac{a}{b}
$$
~~~~

公式使用 MathML 和 TeX 註解，採用 [FEP-dc88] 所描述的方式。
無效運算式、不安全命令或達到呈現上限的公式，會顯示為經過跳脫的原始文字。
各個運算式的巨集狀態相互獨立，並限制展開次數和大小。

上限為每個運算式 8,192 個 UTF-16 程式碼單元、每篇貼文 64 個運算式、
每個運算式輸出 256 KiB，以及公式總輸出 1 MiB。
當貼文原始文字超過 65,536 個 UTF-16 程式碼單元時，僅關閉公式解析；
一般 Markdown、提及、主題標籤和連結處理仍會繼續。
此時，美元符號內的文字也遵循一般 Markdown 規則，不再作為受保護的公式。

[FEP-dc88]: https://w3id.org/fep/dc88


在其他伺服器上閱讀
------------------

接收伺服器和客戶端可能會移除格式。上下標、醒目標示、插入標記和縮寫提示可能遺失。
重要的更正和定義應寫在可見的正文中。
Mastodon 和 Misskey 對注音的支援取決於內容和接收版本。

Mastodon 可能將公式註解顯示為帶美元符號的 TeX 文字，這並不保證公式排版。
Misskey 可能將公式顯示文字和 TeX 註解連接在一起。
不同伺服器和客戶端的顯示可能不同。
當公式承載重要含義時，請附上一般語言的說明。
